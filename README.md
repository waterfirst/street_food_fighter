# Street Food Fighter

Mobile web prototype for live food truck discovery.

## Features

- Driver mode: start business using photo GPS EXIF or current location
- Food category emoji markers on map
- Customer view: find open food trucks around current location
- Radius filter from 0.5 km to 10 km
- Daily reset at 7 AM based on browser storage
- GitHub Pages deployment workflow

## Demo URL

https://waterfirst.github.io/street_food_fighter/

## Note

This first version stores data in browser localStorage. For a real multi-user service, connect Firebase, Supabase, or another shared database.
